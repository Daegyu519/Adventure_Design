# 작업 지시서 모음 (다른 사람·다른 AI용)

각 파일이 **AI에게 그대로 줄 수 있는 지시서**다. 사람은 AI에게 이렇게만 말하면 된다:

> `Daegyu519/Adventure_Design` 저장소에서 `docs/handoff/<ID>.md` 지시서대로 작업해 줘. 먼저 `AGENTS.md`, `CLAUDE.md`, 그 지시서를 읽어.

## 모든 작업 공통
1. **준비**: 저장소 접근(소유자에게 GitHub 초대 요청), Node 20+, `uv`(Python 3.11). 앱 `cd apps/mobile && npm ci`, 엔진 `cd engine && uv sync`.
2. **키·비밀값**: 필요한 작업만 소유자에게 따로 받는다. `.env`·`.env.pilot*` 파일에만 넣고 **커밋·채팅 붙여넣기 금지**. 키 없이 되는 작업은 `FORCE_MOCK=1`과 테스트(mock 공급자)로 한다.
3. **겹침 방지**: 시작 전에 `AGENTS.md` §3 표에 `작업 | 누구 | 상태` 한 줄을 넣고 `git push origin main`. 이미 있는 작업은 잡지 않는다.
4. **흐름**: `scripts/claim <ID> <이름>` → 마지막 줄 worktree에서 작업 → 브랜치를 바로 push → 끝나면 `docs/tasks.md`의 그 행을 `완료` + `확인:` 한 줄 → `scripts/land <ID>`(검사·평가 게이트) → `AGENTS.md` §2·§3·§4 갱신 → `git push origin main`.
5. **규칙**: `CLAUDE.md`의 "어기면 안 되는 규칙" 16개. 특히 앱에 모델·서비스 키 금지(1), LLM 출력은 스키마 통과만(3), 힌트 문구는 템플릿·금지어 검사(4), 하소연 원문 저장 금지(5), 힌트가 전송을 막지 않음(6), 엔진 장애가 채팅을 막지 않음(11), 모델로 가는 문장은 Masker를 거침(16).
6. **지금 Claude가 하는 일**: P-12(실시간 모델 교체) — `engine/config/models.yaml`의 실시간 전문가·게이트를 바꾸는 중이니 그 부분은 피하고, 꼭 필요하면 P-12가 land된 뒤에 한다.
