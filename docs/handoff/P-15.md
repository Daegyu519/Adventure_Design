# P-15 — 파일럿 지표 집계·그래프

영역: 평가 (`eval/`). 먼저 읽기: `AGENTS.md`, `CLAUDE.md`, [README 공통 규칙](README.md), `supabase/migrations/*`(특히 `tone.analysis_traces`, `public.tone_events`, `tone.feedback_log`), T-31 행, `docs/tasks.md`의 `P-15` 행.
시작: `scripts/claim P-15 <짧은-이름>`. 끝: `P-15` 행을 완료 + `확인:` → `scripts/land P-15` → `AGENTS.md` 갱신 → push.

## 할 일
- `eval/pilot_stats.py`: DB 주소(`SUPABASE_DB_URL`, 환경 변수로만)를 받아 **날짜별** 힌트 요청 수, 경로별 결과 비율(`gated`/`abstain`/`alert`/`none`), 지연 p50·p95, 모델 실패, 털어놓기 수, 앱 이벤트(`tone_events` — 힌트를 보고 고친 비율 등)를 표(마크다운)와 그래프(PNG)로 낸다.
- 개인 식별 최소화: user_id는 세지 기만 하고 출력하지 않는다. 문장은 이 표들에 원래 없다(규칙 5).
- 발표용(T-31): "알림 수 변화", "고친 비율" 그래프.

## 하지 말 것
- DB에 쓰기, 원문이 있을 수 있는 표(`public.messages`) 읽기.

## 완료 기준
- 가짜 데이터(테스트 픽스처)로 표·그래프가 만들어지는 pytest. 소유자가 pilot DB 주소로 한 번 돌릴 수 있는 명령을 README에.

## 확인 방법
`cd engine && uv run pytest -q -W error`(새 테스트 포함), `scripts/check`.
