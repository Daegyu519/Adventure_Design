# LIVE — 실제 앱으로 기능 확인 (-live 행들)

사람이 앱을 쓰고 AI가 기록을 돕는 작업. 키가 필요 없다(앱 계정만). 먼저 읽기: `AGENTS.md`, [README 공통 규칙](README.md), `docs/tasks.md`에서 이름이 `-live`로 끝나는 행들(T-07-live ~ T-28a-live)의 완료 기준.

## 어디서
- 웹 `https://tone-chat.expo.app`(아이폰은 Safari → 공유 → 홈 화면에 추가), Android APK는 소유자에게 링크를 받는다.
- 계정 2~3개(서로 다른 이메일, 개인 메일 권장 — 스팸함 확인).

## 할 일
1. 각 `-live` 행의 완료 기준을 실제로 해 본다: 로그인(코드 메일), 1:1 초대·수락, 그룹방(최대 8명), 사진, 공감·답장·멘션, 읽음 수, 알림 끄기, 푸시(웹·Android), 털어놓기, 거울, 설정.
2. 되면 그 행 끝에 `확인: <날짜> <기기/브라우저> <무엇을 봤는지>`, 상태 `완료`. 안 되면 행은 그대로 두고 `AGENTS.md` §9에 증상(화면·순서·기기)을 적는다. 화면 캡처에 다른 사람의 대화가 보이면 올리지 않는다.
3. 기록은 한 브랜치로: `scripts/claim LIVE live-check` → 행 고치기 → `scripts/land LIVE`(tasks의 LIVE 행이 필요하면 추가) → push.

## 알아둘 것
- 말투 힌트가 거의 안 뜨는 건 알려진 문제(P-12에서 고치는 중)다.
- Android에서 앱이 꺼져 있을 때 푸시는 아직 없다(P-17).
