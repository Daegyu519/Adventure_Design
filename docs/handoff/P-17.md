# P-17 — Android 푸시(FCM) 연결 준비

영역: 앱(`apps/mobile`). 먼저 읽기: `AGENTS.md`, `CLAUDE.md`, [README 공통 규칙](README.md), `apps/mobile/app.json`, `apps/mobile/eas.json`, `apps/mobile/lib/push*.ts`, `engine`의 푸시 발송 부분, Expo 문서 "Push notifications setup — Android FCM", `docs/tasks.md`의 `P-17` 행.
시작: `scripts/claim P-17 <짧은-이름>`. 끝: `P-17` 행을 완료 + `확인:` → `scripts/land P-17` → `AGENTS.md` 갱신 → push.

## 할 일
- 소유자가 Firebase 프로젝트를 만들면(패키지 `kr.ac.cnu.tonechat`) 나오는 `google-services.json`을 **저장소에 넣지 않고** EAS file 환경 변수로 받아 빌드에 쓰는 설정(`app.config` 또는 `app.json` `android.googleServicesFile`를 EAS env로).
- FCM V1 서비스 계정 키를 EAS 자격 증명에 올리는 순서를 docs/OPERATIONS.md에(사람이 할 일로).
- 앱이 푸시 토큰을 못 얻어도 조용히 넘어가는지(채팅 영향 없음) 테스트 확인.

## 하지 말 것
- 키 파일 커밋, iOS 네이티브 푸시(아이폰은 웹 푸시).

## 완료 기준
- 설정과 문서가 있고, 키가 없을 때도 빌드·테스트가 통과한다. 소유자가 키를 넣고 `eas build -p android --profile preview` 한 번이면 되게.

## 확인 방법
`cd apps/mobile && npm test`, `scripts/check`.
