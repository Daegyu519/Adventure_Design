# P-16 — 대조 세트 라벨 도구 (T-16을 쉽게)

영역: 평가 (`eval/`). 먼저 읽기: `AGENTS.md`, `CLAUDE.md`, [README 공통 규칙](README.md), `eval/contrast_set.jsonl`(형식: pair, side A/B, relation, them, draft, alert), `eval/run_eval.py`, T-16 행, `docs/tasks.md`의 `P-16` 행.
시작: `scripts/claim P-16 <짧은-이름>`. 끝: `P-16` 행을 완료 + `확인:` → `scripts/land P-16` → `AGENTS.md` 갱신 → push.

## 할 일
- T-16 = "같은 문장, 다른 맥락" 30쌍을 **두 사람이 따로(블라인드)** 라벨한 뒤 합의한다. 이걸 쉽게 하는 도구.
- `eval/label/`: (1) 후보 쌍 목록(사람이 쓰거나 템플릿으로 만든 초안)을 무작위 순서·정답 가린 형태로 내보내는 명령, (2) 브라우저에서 여는 단순 HTML 폼 또는 CSV 양식(라벨: 차갑게 읽힘 예/아니오 + 메모), (3) 두 사람 결과를 합쳐 **일치율·Cohen's kappa**와 불일치 목록을 내는 명령, (4) 합의본을 `eval/contrast_set.jsonl` 형식으로 쓰는 명령.
- 30쌍 초안 예시 10개 정도를 함께 넣어 시작을 돕는다(관계·상황 다양하게: 친구/연인/선후배/직장, 위로/거절/축하/약속).

## 하지 말 것
- 사람 대신 라벨을 정하기(최종 라벨은 사람이), 실제 대화 넣기.

## 완료 기준
- 도구로 내보내기→두 사람 라벨→합치기→jsonl 생성이 끝까지 되고, kappa 계산 테스트가 있다.
