# R-01 인터뷰 질문지

작성: 2026-11-10 · 연결: [feedback-roadmap.md](../feedback-roadmap.md) §1 R-01

한 사람당 **15분 안쪽**. 탐색용이며 시장 규모의 증거로 쓰지 않는다.

## 진행 전에

- 대상: 조원 N명 + 가능하면 외부 1~2명. 발표에는 "조원 N명·외부 M명, 탐색용"으로 밝힌다.
- 우리 앱을 먼저 소개하지 않는다. 기능을 설명하면 "있으면 좋겠다"는 답만 나온다. 소개는 마지막 5번에서만 한다.
- 대화 원문은 받지 않는다. "어떤 상황이었는지"만 말로 듣는다. 캡처를 보여 주려 하면 정중히 사양한다.
- 녹음하지 않고 메모만 한다. 이름 대신 `P1`, `P2`로 적는다.
- "쓰겠다/안 쓰겠다"보다 **실제로 한 행동, 걸린 시간, 얼마나 자주**를 적는다.

시작 멘트 예시:
> 메시지 보낼 때 어떻게 하는지 15분만 물어볼게. 정답은 없고, 최근에 실제로 있었던 일 위주로 얘기해 주면 돼.

## 1. 최근 경험 (5분)

1. 최근 한 달 안에 **보내기 전에 오래 고민하거나 여러 번 고친 메시지**가 있었어? 어떤 상황이었어?
   - 누구한테(관계), 무슨 내용(부탁/재촉/거절/사과/기타)이었는지
2. 그때 몇 번 정도 고쳤고, 보내기까지 대략 얼마나 걸렸어?
3. 뭐가 제일 걱정됐어? (차갑게 보일까, 화난 것처럼 보일까, 만만해 보일까, 기타)
4. 보낸 뒤에 실제로 어떻게 됐어? 걱정한 일이 일어났어?

> 경험이 없다고 하면: "팀플에서 누군가에게 마감을 재촉하거나, 부탁을 거절해야 했던 적"으로 좁혀서 다시 묻는다.

## 2. 지금의 대처 방법 (3분)

5. 그럴 때 보통 어떻게 해? (혼자 여러 번 고침 / 친구한테 보여 줌 / ChatGPT 같은 AI에 물어봄 / 그냥 보냄 / 기타)
6. AI나 다른 사람한테 확인해 본 적 있으면, 뭐가 도움이 됐고 뭐가 불편했어?
7. 이런 고민은 얼마나 자주 해? (거의 매일 / 주 1~2번 / 한 달에 몇 번 / 거의 없음)

## 3. 도움과 간섭의 경계 (3분)

8. 메시지를 보내기 전에 누가 "이렇게 읽힐 수도 있어"라고 알려 주면 **좋을 것 같은 순간**은?
9. 반대로 **알려 주면 짜증 날 것 같은 순간**은? (친한 친구, 급할 때, 일부러 단호하게 쓸 때 등)
10. 일부러 단호하게 쓴 말(거절, 재촉)을 "부드럽게 바꿔 보세요"라고 하면 어떨 것 같아?

## 4. 쓰는 메신저 (1분)

11. 팀플이나 친구 연락은 주로 어디서 해? (메신저 이름만 기록)
12. 그 메신저에서 쓸 수 있으면 좋겠어, 아니면 따로 앱을 열어도 괜찮아? 키보드 앱을 바꿔 설치하는 건 어때?

## 5. 마지막에만: 이름 반응 (3분)

여기서 처음으로 기능을 한 줄씩 설명하고 첫인상을 묻는다.

13. "상대가 내 메시지를 받았을 때 어떻게 느낄지 미리 상대 입장에서 연습해 보는 기능"이 있다면, 아래 이름 중 **설명 없이 무슨 기능인지 알 것 같은 것**은?
    - 거울 모드 / 대화 연습 / 상대 입장에서 읽기 / 답장 연습 / 어떻게 들릴까?
14. 위 기능이 있다면 언제 써 볼 것 같아? (안 쓸 것 같으면 왜?)
