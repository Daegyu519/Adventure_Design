## 데이터

- 후보 30쌍(60문장, AI 초안). 각 쌍은 같은 답장에 상대 말만 다르게 붙였다. 설계 의도는 A=괜찮은 맥락, B=알려 줄 만한 맥락.
- 라벨러 5명(L1~L5, 조원). 상의 없이 각자, 링크 페이지 1명·제출 코드 4명. **5명 중 2명은 프로젝트를 잘 아는 팀원**이라 순수한 사용자 판단과는 거리가 있다.
- 합의본: `eval/contrast_set_t16.jsonl`(다수결 3/5), 보고서: `eval/contrast_set_t16.report.json`. 원본 제출(실명 포함)은 `eval/label/out/`(git 밖).

## 사람끼리의 일치도

| | 값 |
|---|---|
| Fleiss kappa (5명) | **0.47** |
| 두 사람씩 kappa 평균 | 0.48 |
| 만장일치 (5:0) | 29개 (알려 줄 만함 17 · 괜찮음 12) |
| 4:1 | 16개 |
| 거의 갈림 (3:2) | 15개 |

- kappa 0.47은 "보통" 수준이다. 사람끼리도 4개 중 1개꼴로 크게 갈린다. **모델에 이보다 훨씬 높은 일치를 기대할 수 없다.**
- 사람별 경고 비율 52~67%, 다수결과의 일치 77~93%. 한 사람이 유독 어긋나지는 않았다.

## 핵심 발견: 맥락보다 문장과 관계로 판단한다

같은 답장을 맥락만 바꿔 놓은 30쌍을 다수결로 보면:

| 결과 | 쌍 수 |
|---|---|
| 설계대로 갈림 (A 괜찮음 / B 알려 줄 만함) | **7** |
| 둘 다 알려 줄 만함 | **15** |
| 둘 다 괜찮음 | **8** |
| 반대로 갈림 | 0 |

사람별로 봐도 설계대로 가른 쌍은 4~10개였다.

**둘 다 알려 줄 만함(15쌍):** 답장 자체가 무시하거나 날카로운 말이다. 맥락이 무난해도 걸렸다.
- "알아서 하세요"(직장, "양식 제가 정해도 될까요?"에도 5/5), "신경 꺼"(형 "집에 내려갈게"에도 5/5), "바빠"(가족 "주말에 볼 수 있어?"에도 5/5), "별로"(로고 시안 골라 달라는데 5/5), "알아서 해"(연인 "저녁 뭐 먹을까?"에 5/5)

**둘 다 괜찮음(8쌍):** 답장이 공손하거나 무난한 말이다. 상대가 감정을 드러낸 맥락이어도 거의 걸리지 않았다.
- "괜찮아"(면접 또 떨어졌다는 친구에게 0/5), "알았어"(아빠, 휴학 얘기 좀 하자에 0/5), "네 알겠습니다"(도와달라는 후배에게 0/5), "확인했습니다"(실수를 사과하는 팀원에게 0/5), "축하해"(시험 붙었는데 너는 어때?에 1/5)

관계별 경고 비율(다수결): 가족 8/10 · 연인 7/10 · 친구 7/12 · 동아리 6/8 · 선후배 6/10 · **직장 3/10**.

메모(알려 줄 만함 153건)에 나온 이유: 공격·띠꺼움·화 44 · 감정 무시·회피 36 · 관계 언급 29 · 성의·짧음 25 · 맥락 언급 20 · 이유·설명 없음 14.

## 해석 (가설)

1. **사람은 "이 맥락에 이 말이 어떤가"보다 "이 말 자체가 날카로운가"와 "누구에게 하는가"로 판단한다.** 우리 제품의 차별점으로 내세운 "같은 문장도 맥락에 따라 다르게 판단"은 사람 판단에서도 30쌍 중 7쌍에서만 나타났다.
2. **"둘 다 괜찮음" 8쌍이 중요하다.** 면접에 떨어진 친구에게 "괜찮아", 휴학을 상의하자는 아빠에게 "알았어"는 말투는 무난하지만 **내용이 상대가 기대한 반응이 아니다.** 사람들은 이걸 "알려 줄 만한 말투"로 보지 않았다. 이건 말투 문제가 아니라 **"뭐라고 답해야 하나"의 문제**다. 11/10 파일럿 응답(P0)의 가설과 같은 방향이다.
3. 날카로운 말("알아서 해", "신경 꺼", "별로")은 맥락 없이도 5명이 거의 다 걸렀다. 이런 건 **복잡한 맥락 모델 없이도 잡힌다**(겉 신호·분류기). 반대로 맥락 모델이 필요한 영역은 2번처럼 말투가 아니라 내용의 문제였다.
4. **후보 세트 자체의 한계:** AI가 만든 "괜찮은 맥락"(A쪽)이 사람에게는 괜찮지 않았다. 맥락 구분 능력을 재려면 세트를 다시 만들어야 한다.

## 이 결과로 할 수 있는 것과 없는 것

- 할 수 있다: "사람끼리 일치도 0.47, 만장일치 29개"를 근거로 **제동은 사람 다수가 동의하는 구간에서만** 건다는 기준. 만장일치 29개는 모델 평가의 "확실한 구간"으로 쓴다.
- 할 수 없다: 이 60개로 "맥락 구분 능력"을 평가하는 것(설계대로 갈린 쌍이 7개뿐). 5명 중 2명이 팀원이라 일반 사용자 판단으로 일반화하는 것.

## LLM 라벨러 비교: Codex (2026-11-13)

같은 60문장과 같은 기준만 주고(쌍 정보·사람 결과 없이) Codex CLI(`codex exec`, 읽기 전용, 1회)에 라벨하게 했다. 결과: `eval/label/out/labels_CODEX.json`(git 밖). 평가 비교용이며 학습 라벨로 쓰지 않는다(P-14b 원칙).

| | 사람 5명 | Codex |
|---|---|---|
| 알려 줄 만함 수 | 31~40 | **27** (가장 관대) |
| 다수결과 일치 | 74~92% (본인 뺀 4명 다수결 기준) | **80%** (48/60, kappa 0.61) |
| 확실한 구간(5:0·4:1, 45개) 일치 | – | 38/45 |
| 맥락대로 가른 쌍 | 4~10 | **11** (가장 많음) |

- 다수결과의 일치는 **보통 사람 라벨러 수준**이다. 보조 라벨러로 쓸 수는 있다.
- 하지만 **틀리는 방향이 사람과 다르다.** 사람은 "알아서 하세요", "바빠", "내가 알아서 할게"처럼 날카로운 말을 무난한 맥락에서도 5명 모두 걸렀는데, Codex는 지침의 "단순 확인·정당한 거절은 괜찮음"을 문자 그대로 적용해 통과시켰다(12개 불일치 중 10개가 이 방향).
- 반대로 기념일에 하루 종일 기다렸다는 연인에게 "고마워"는 사람 2/5였지만 Codex는 "서운함을 지나쳤다"며 걸렀다. **Codex는 맥락·상대 기대로, 사람은 말 자체와 관계로** 판단하는 경향이다.
- 즉 LLM 라벨로 평가 세트를 채우면, 우리 모델(LLM)이 **사람보다 LLM에 맞춰지는 쪽**으로 기울 수 있다. 최종 평가 기준은 사람 라벨로 둔다.
