# R-01 경쟁 비교 시나리오

작성: 2026-11-10 · 연결: [feedback-roadmap.md](../feedback-roadmap.md) §1 R-01

같은 시나리오를 여러 도구에 넣고, 같은 기준으로 비교한다. 결과는 발표의 "기존 제품과 무엇이 다른가"에 쓴다. 차별점은 검증 전까지 **가설**로 표시한다.

## 비교 대상

| 도구 | 넣는 방법 | 메모 |
|---|---|---|
| 우리 앱 (OOPS!) | 앱 대화방에서 상대 말 다음에 초안 입력 → 보내기 | 배포 버전 기준 |
| ChatGPT (또는 Claude 등 일반 LLM) | 아래 "LLM에 넣을 문장" 그대로 붙여 넣기 | 무료 버전, 새 대화에서 |
| 삼성 글쓰기 어시스트 | 갤럭시 키보드에서 초안 입력 → 글쓰기 어시스트 → 어조 변경 | 갤럭시 기기 필요 |
| Grammarly | 한국어 지원이 약하면 "한국어 미지원"으로 기록하고 끝 | 지원 여부 자체가 결과 |

시나리오는 모두 **지어낸 예문**이다. 실제 대화를 넣지 않는다.

## 시나리오

모두 대학생 팀플 상황. "지킬 의도"는 고쳐 쓴 문장에서 사라지면 안 되는 것이다.

### S1. 재촉 — 마감 하루 전 자료 미제출

- 관계: 같은 조 동기 (반말 사이)
- 상대가 마지막으로 한 말: `ㅇㅋ 내일까지 할게` (사흘 전)
- 보낼 초안: `너 자료 아직도 안 올렸어? 내일 발표인데`
- 지킬 의도: **오늘 안에 올려야 한다**는 기한

### S2. 거절 — 추가 역할 떠넘기기

- 관계: 조장 (존댓말 사이)
- 상대: `ㅇㅇ님 혹시 PPT도 같이 맡아 주실 수 있을까요? 제가 이번 주 너무 바빠서요 ㅠ`
- 보낼 초안: `저도 바빠서 안 될 것 같아요.`
- 지킬 의도: **거절**(맡지 않는다). 수락처럼 들리면 실패

### S3. 부탁 — 연락 없는 조원에게 확인

- 관계: 거의 대화해 본 적 없는 조원 (존댓말)
- 상대: (이틀째 단톡방에 답 없음)
- 보낼 초안: `혹시 단톡 보셨나요? 답이 없으셔서요`
- 지킬 의도: **답을 달라**는 요청. 지나치게 미안해하며 흐려지면 실패

### S4. 맥락에 따라 달라지는 짧은 답

- 관계: 같은 조 친구 (반말)
- 상대: `나 이번 발표 진짜 망칠 것 같아.. 어제 한숨도 못 잤어`
- 보낼 초안: `ㅇㅇ 알아서 해`
- 지킬 의도: (특별히 없음) — **맥락을 보고 경고하는지**를 본다
- 대조: 같은 초안을 상대 말이 `발표 자료 내가 마저 정리할까?`일 때도 넣는다. 이때는 경고가 없어야 정상

## LLM에 넣을 문장

도구마다 맥락을 줄 수 있는 만큼만 준다. LLM은 아래를 그대로 붙여 넣는다(시나리오마다 새 대화).

```
대학교 팀플 단톡에서 [관계]에게 메시지를 보내려고 해.
상대가 마지막으로 한 말: "[상대 말]"
내가 보낼 말: "[초안]"
이 메시지 보내도 괜찮을까? 문제가 있으면 고쳐 줘.
```

※ 사람들이 실제로 쓰는 방식에 가깝게 일부러 짧게 묻는다. "의도를 지켜 줘" 같은 말은 넣지 않는다.

### 칸 설명

- **사용 단계 수**: 메시지를 쓰기 시작해서 고친 문장을 보낼 수 있게 되기까지 누른 횟수(앱 전환, 복사, 붙여 넣기 포함).
- **필요한 권한·설치**: 새 앱 설치, 키보드 교체, 상대도 같은 앱 필요 여부. 우리 앱은 "상대도 가입해야 함"을 솔직히 적는다.
- **맥락 반영**: 상대 말을 보고 판단했는가. S4 대조 쌍에서 두 경우를 구분했으면 2.
- **의도·단호함 유지**: 고친 문장이 기한·거절·요청을 지웠거나 흐렸으면 0.
- **설명 구체성**: "더 부드럽게"만 말했으면 0, 어느 구절이 왜 그렇게 읽힐 수 있는지 말했으면 2.
- **상대 입장 연습**: 받는 사람 입장에서 미리 느껴 보는 기능이 있는가.

## 결과에서 볼 것 (가설)

결과를 보기 **전에** 적어 두고, 결과와 다르면 그대로 기록한다.

- H1. 일반 LLM은 고쳐 쓰기를 잘하지만 단호함(S1 기한, S2 거절)을 약하게 만드는 경우가 있다.
- H2. 키보드 어조 변경은 맥락(상대 말)을 보지 못해 S4 대조 쌍을 구분하지 못한다.
- H3. 우리 앱은 맥락을 보지만, 상대도 같은 앱을 써야 한다는 장벽이 가장 크다 → R-03 외부 연결 실험의 근거.

H3은 우리 쪽 약점이다. 발표에서 숨기지 않고 R-03으로 이어지는 이유로 쓴다.
