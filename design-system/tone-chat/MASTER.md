# tone-chat 디자인 시스템 (MASTER)

> 화면별 규칙이 필요하면 `design-system/tone-chat/pages/<화면>.md`를 만든다. 그 파일이 있으면 이 파일보다 우선한다. 없으면 이 파일을 따른다.

- **원본**: ui-ux-pro-max `--design-system`(Chat & Messaging App, variance 3 / motion 3 / density 5)을 스펙 7장 결정으로 고쳤다. 버린 것은 맨 아래.
- **토큰 원본**: `apps/mobile/lib/tokens.json`. 이 문서의 값과 다르면 tokens.json이 맞다. 앱(Task 8)과 목업(`design/mockups/index.html`)은 이 파일 값을 그대로 쓴다.
- **검사**: `python3 design/check_contrast.py` → `contrast OK`. 색을 바꾸면 다시 돌린다.

## 1. 원칙

1. **조용하게, 판단하지 않게.** 힌트는 보내는 사람에게만, 한 줄로, 확정하지 않는 말로 뜬다. 경고·오류처럼 보이지 않는다.
2. **전송을 막지 않는다.** 힌트가 있어도 전송 버튼은 그대로다. 모달로 가로막지 않는다.
3. **출처를 짐작하게 하지 않는다.** 누가 불편해했는지, 누가 털어놓았는지 드러내는 문구·숫자·표시를 쓰지 않는다.
4. **점수가 아니라 차이.** 거울·리포트는 등급·순위·잘함/못함 색을 쓰지 않는다. "예측과 한 칸 차이"처럼 차이로만 말한다.
5. **다른 메신저처럼 보이지 않는다.** 카카오톡·인스타그램·디스코드의 이름·로고·색·에셋을 쓰지 않는다. 노란색·갈색 계열 금지, 꼬리 달린 말풍선 금지.

## 2. 색

차분한 틸(주색), 중립 회색, 힌트용 앰버, 거울용 라벤더. 빨강(`danger`)은 오류에만 쓴다.

| 토큰 (tokens.json) | CSS 변수 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|---|
| `primary` | `--primary` | `#0F766E` | `#2DD4BF` | 내 말풍선, 주 버튼, 선택된 칩, 안 읽은 수, 활성 탭 |
| `onPrimary` | `--on-primary` | `#FFFFFF` | `#042F2E` | primary 위 글자·아이콘 |
| `bubbleOther` | `--bubble-other` | `#F1F5F4` | `#1E2B2A` | 받은 말풍선, 아바타 바탕 |
| `onBubbleOther` | `--on-bubble-other` | `#0F172A` | `#E6EEEC` | 받은 말풍선 글자 (= `text`) |
| `background` | `--background` | `#FFFFFF` | `#0B1211` | 화면 바탕 |
| `surface` | `--surface` | `#F7FAF9` | `#121A19` | 시트 안 상자, 카드, 입력창 바탕 |
| `text` | `--text` | `#0F172A` | `#E6EEEC` | 본문 |
| `textMuted` | `--text-muted` | `#5B6B68` | `#94A3A0` | 시간, 미리보기, 보조 설명 |
| `border` | `--border` | `#E2E8E6` | `#26332F` | 구분선, 테두리 |
| `hintBg` | `--hint-bg` | `#FFF7ED` | `#2A1E12` | 힌트 줄 바탕 (힌트에만) |
| `hintText` | `--hint-text` | `#9A3412` | `#FEE7CF` | 힌트 글자·앰버 점 (힌트에만) |
| `mirror` | `--mirror` | `#7C3AED` | `#A78BFA` | 거울 탭 강조 (거울에만) |
| `onMirror` | `--on-mirror` | `#FFFFFF` | `#1E1B2E` | mirror 위 글자 |
| `danger` | `--danger` | `#DC2626` | `#F87171` | 전송 실패·오류 (힌트에 쓰지 않음) |

- **대비 (검사 대상, 두 모드 모두 4.5:1 이상)**: text/background, textMuted/background, onPrimary/primary, onBubbleOther/bubbleOther, hintText/hintBg, onMirror/mirror, danger/background. 스펙 7장 시작 값이 대비는 모두 통과했다.
- **노란·갈색 금지 (검사)**: HSL 색상각 20°~65°(갈색~노랑)이면서 채도 > 0.5, 명도 < 0.9인 색은 쓰지 않는다. 명도 0.9 이상인 아주 옅은 색만 예외. 라이트 힌트 글자 `#9A3412`는 색상각 15°라 범위 밖이다.
- **보정 1건**: 다크 `hintText`는 스펙 시작 값 `#FDBA74`(색상각 31°, 채도 0.97, 명도 0.72)가 갈색 범위에 걸려, 색상각·채도는 두고 명도만 0.90으로 올려 `#FEE7CF`로 바꿨다(hintBg 위 대비 13.6). 다크 힌트는 진한 따뜻한 바탕 위 옅은 크림색 글자로 보인다.
- **파생 색은 하나만**: 시트 뒤 가림막 `--scrim` = 라이트 `color-mix(text 32%, transparent)`, 다크 `color-mix(background 72%, transparent)`. 그 밖에 토큰에 없는 색을 만들지 않는다. 그림자도 쓰지 않고 `border`로 층을 나눈다.
- 다크 모드는 시스템 설정을 따르고 설정 화면에서 바꿀 수 있다.

## 3. 글꼴

- **Pretendard** (OFL). 앱은 `expo-font`로 포함, 웹 목업은 jsDelivr CDN. 대체: `-apple-system, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`.
- 크기 세 개만: `title` 20 (화면 제목, 시트 제목, 결과 한 줄) · `body` 16 (말풍선, 본문, 버튼) · `small` 13 (시간, 미리보기, 힌트, 칩 아래 설명, 각주). 줄 간격 1.5.
- 굵기 400 / 600 두 개만. 900·초대형 글자 금지.
- 한국어 줄바꿈: `word-break: keep-all`.

## 4. 간격 · 모서리 · 아이콘

- 간격 `space`: 4, 8, 12, 16, 20, 24, 32. 화면 좌우 여백 16, 말풍선 사이 4(같은 사람)·12(사람 바뀜).
- 모서리 `radius`: 말풍선 18, 시트 위 모서리 20, 칩·배지·입력창 999(알약), 카드 16.
- 아이콘: **Lucide** (`lucide-react-native`), 24px, 선 굵기 2, `currentColor`. 이모지를 아이콘으로 쓰지 않는다. 공감 이모지는 메시지 내용이라 예외.

## 5. 컴포넌트

### 말풍선
- **꼬리 없음**, 네 모서리 18. 최대 너비 75%.
- 내 것: 오른쪽, `primary` / `onPrimary`. 받은 것: 왼쪽, `bubbleOther` / `onBubbleOther`. 그룹방은 첫 말풍선 위에 이름(13, `textMuted`)과 36px 아바타.
- 읽음: 내 말풍선 옆에 **안 읽은 사람 수**(13, 600, `primary`)와 시간(13, `textMuted`). 모두 읽으면 숫자를 지운다.
- 답장 인용: 말풍선 안 위쪽, 왼쪽 2px 선 + 원문 보낸 사람·첫 줄(13). 탭하면 원문으로 이동.
- 공감: 말풍선 아래 알약 칩(이모지 + 수, 13). 고정 6개, 한 사람 하나.
- 입력 중: 받은 말풍선 자리에 점 3개(`textMuted`). 스크린리더용 "○○ 님이 입력 중이에요".
- 받은 메시지에만 "⋯"(털어놓기 진입). 내 메시지에는 없다.

### 힌트 (입력창 위 한 줄)
- 모양: 입력창 바로 위 한 줄, 알약 모양, `hintBg` 바탕. 왼쪽부터 **앰버 점**(8px, `hintText`) · 제목 "차갑게 느껴질 수도 있어요"(13) · "살펴보기 ›"(13, 600) · 닫기(X). 글자는 모두 `hintText`.
- 한 번에 하나만. 제목은 템플릿 세 개 중 하나("차갑게 / 성의 없게 / 화난 것처럼 느껴질 수도 있어요").
- 전송 버튼 모양·동작은 바뀌지 않는다. 힌트가 떠 있어도 바로 보낼 수 있다.
- 빨강·경고 아이콘·진동을 쓰지 않는다.
- 움직임: 나타날 때 아래 8px에서 올라오며 투명 → 불투명, 200ms ease-out. 사라질 때 150ms 투명. 동작 줄이기가 켜져 있으면 이동 없이 투명도만 바꾼다.

### 살펴보기 시트
- 아래에서 올라오는 시트, 위 모서리 20, 손잡이, 제목 "살펴보기" + 닫기.
- 순서: 보낼 문장 → **의도 칩** "단호하게 / 미안하게 / 가볍게"(고르지 않아도 됨, 선택 시 `primary` 바탕) → **이렇게 읽힐 수 있어요**(읽힘 이름 + "자주 / 가끔 / 드물어요" 세 단계 글자와 점 3개, 퍼센트 금지) → **이유** 두 줄 → **후보 A/B**(라디오 카드, 원문과 달라진 어절만 `primary` 글자 + 밑줄) → 각주 → 버튼 "그대로 보낼게요"(보조) · "입력창에 적용"(주).
- 어긋남 한 줄은 의도와 가장 많이 읽힌 뜻이 어긋날 때만(스펙 5장 표).
- 각주: "비슷한 대화에서 모인 반응을 바탕으로 한 조언이라 틀릴 수도 있어요. 누가 어떤 반응을 남겼는지는 알 수 없어요."

### 털어놓기 시트
- 받은 메시지 인용(보낸 사람·시간·문장) → 여러 줄 입력(1~1000자, 글자 수) → 안내 상자(`surface`) → 주 버튼 "털어놓기".
- 안내: 적은 글은 저장되지 않고 상대에게 전달되지 않는다는 것, 누가 남겼는지 드러나지 않게 조심스럽게 반영될 수 있다는 것. 무엇이 추출됐는지는 보여 주지 않는다.

### 거울 카드
- 카드(모서리 16, `surface`, `border`). 위에 종류 칩(`mirror` / `onMirror`): 역할극 · 되돌려 받기 · 예측 맞히기. 진행 점 3개.
- 1~5칸 선택: 44px 이상 칸 다섯 개(라디오), 양끝 설명 "덜 부정적 / 많이 부정적". 고른 칸은 `mirror` 바탕.
- 결과: "예측과 한 칸 차이"(20, `mirror`) + 문장에 대한 한두 줄. 사람을 평가하지 않는다.

### 리포트
- 숫자 세 개(예측 차이 · 이번 주 힌트 · 스스로 고친 비율) + 주별 힌트 수 막대.
- 막대 하나의 색(`primary`가 이번 주, 지난 주들은 `textMuted`), 위 모서리 4px, 막대 사이 간격, 값은 글자색 토큰. 순위·등급·빨강/초록 판정 금지.

### 버튼 · 칩 · 입력
- 주 버튼: `primary` 바탕, `onPrimary` 글자, 높이 48, 모서리 999, 16/600.
- 보조 버튼: `surface` 바탕, `border` 테두리, `text` 글자.
- 아이콘 버튼: 44×44, `aria-label` 필수.
- 칩: 높이 44(터치 영역), 모서리 999. 선택은 `primary` 바탕 + `aria-pressed`.
- 입력창: `surface` 바탕, `border` 테두리, 모서리 22, 16.
- 탭바: 대화 · 거울 · 리포트 · 설정. 활성 `primary`, 나머지 `textMuted`. 아이콘 + 글자(13).

## 6. 움직임

- 150~250ms, `ease-out`(들어올 때)·`ease-in`(나갈 때). `transform`·`opacity`만 움직인다.
- 시트: 아래에서 올라옴 250ms. 힌트: 위 5장 규칙.
- **동작 줄이기**(`prefers-reduced-motion` / RN `AccessibilityInfo.isReduceMotionEnabled`)를 따른다: 이동을 빼고 투명도만.
- 진동 없음(힌트·시트 모두). 애니메이션 라이브러리는 RN 기본 `Animated` 또는 Reanimated. GSAP 쓰지 않는다.

## 7. 문구

- 한국어, 확정하지 않는 말투: "~일 수도 있어요", "~하기도 해요", "~일 수 있어요".
- 금지어(엔진 검사와 같음): 확실히, 분명히, 반드시, 상대가 말하길, 상대방이 그러는데, 님이 말한, 피드백을 남겼, 싫어했어요, 기분 나빠했어요.
- 사람이 아니라 문장을 말한다("이 문장은 ~처럼 읽힐 수도 있어요").
- 버튼은 사용자의 말로: "그대로 보낼게요", "입력창에 적용", "털어놓기".

## 8. 접근성

- 대비 4.5:1 이상(`check_contrast.py`), 터치 영역 44pt 이상, 아이콘만 있는 버튼은 스크린리더 라벨.
- 키보드·스위치 포커스가 보이게(`primary` 2px 테두리).
- 색만으로 뜻을 전하지 않는다: 힌트는 글자, 읽힘은 단계 글자, 선택은 `aria-pressed`/`aria-checked`.
- 글자 크기 키움(Dynamic Type)에서 힌트 줄은 두 줄까지 늘어나도 된다.

## 9. 금지

- 노란색·갈색 계열, 꼬리 달린 말풍선, 그라데이션 말풍선, 다른 메신저의 색·아이콘·이름.
- 힌트에 빨강·경고 삼각형·진동·모달.
- 점수·등급·순위·잘함/못함 색.
- 이모지 아이콘, 초대형 글자, 화려한 장식, 그림자 겹치기.
- 레이아웃이 밀리는 hover(scale), 바로 바뀌는 상태(150ms 이상 전환), 보이지 않는 포커스.

### 도구 원본 추천에서 버린 것

ui-ux-pro-max가 낸 원본에서 다음을 버렸다. 색(Messenger blue `#2563EB` + 초록 CTA)은 차분한 틸·앰버·라벤더로 바꿨다 — 파랑+초록은 기존 메신저 느낌이 강하고, 힌트·거울처럼 역할마다 색을 따로 둬야 해서다. 글꼴 Lora/Raleway는 한글이 없어 Pretendard로 바꿨다. 스타일 "Exaggerated Minimalism"(초대형 900 글자, 큰 여백)은 패션·포트폴리오용이라 조용한 채팅과 맞지 않아 뺐다. 페이지 패턴 "App Store Style Landing"(별점·다운로드 버튼)은 랜딩 페이지용이라 앱 화면과 관계가 없어 뺐다. 움직임 예시의 GSAP 코드는 React Native에서 쓰지 않으므로 빼고 시간(150~250ms)과 동작 줄이기 규칙만 남겼다. hover 들어 올리기·카드 그림자·`cursor:pointer` 같은 웹 전용 규칙은 터치 앱이라 뺐다(목업 HTML에서만 씀). 남긴 것은 범주 판단(미니멀 + 작은 상호작용, 보낸/받은 말풍선 대비, 입력 중 회색), 대비 4.5:1, 이모지 아이콘 금지, 보이는 포커스, 동작 줄이기 체크리스트다.
